# Pacific Front 自动排阵与游玩

当前版本：**v2.6.0**。全功能适配《战舰世界》“大洋战线 / 太平洋前线（Pacific Front）”网页行动，支持亚服、欧服、美服和国服。

将 [pacific-front-auto.user.js](./pacific-front-auto.user.js) 全文替换到油猴（Tampermonkey）中的旧脚本并保存，刷新游戏网页，确认控制面板版本显示为 **v2.6.0**。完整战术逻辑、配置参数及高难实操指南见 [使用说明](./使用说明.md)。

## 核心战术亮点 (v2.6.0)

- **“全局贪婪仓鼠”资源哲学**：
  - **资产绝对安全**：彻底移除自动扣款代买机制，杜绝擅自消耗玩家活动货币；
  - **用多不用少**：同等达标条件下，优先消耗库存充裕的道具，保护个位数稀缺战略库存；
  - **以小博大**：支持使用廉价可再生的白色战力修改器，搭配存量充裕的绿色特殊修改器破局，平替稀缺高阶道具。
- **30/30 盟军全舰艇白蓝黄三色九阶硬分档**：
  - 严格构建 9 阶战力阶梯（高/中/基 黄、高/中/基 蓝、高/中/基 白）；
  - **卡牌防战力溢出遍历**：严格按白到黄、战力升序逐级推演，达标即止，坚决不用大船打小怪（90 能赢坚决不上 105）。
- **四阶 SOP 双插槽合体攻坚流水线**：
  - 单槽攻坚遵循：`纯裸卡 ＞ 单白战力 ＞ 单绿特殊 ＞ 绿+白双插槽合体`；
  - 针对五星高难 Boss 据点，允许在装载特殊道具的基础上追加白战力，彻底攻克单道具卡在 76% 胜率的瓶颈，稳锁 100% 满胜率。
- **战略资源掉落驱动的动态胜率保护**：
  - **进度代币 (👑)**：数额 $\ge 100$ 的大额代币槽 100% 必拿，并强制装配【效率】书（+10% 代币获取）；
  - **煤炭资源 (💎)**：确权为 95% 战略保护目标，严防弃坑，绝不把 55 煤炭当杂鱼丢弃；
  - **快速维修包 (🔧)**：95% 绝不翻车；维修道具平级调度，严格遵循血量战力折损与满血 3 HP 上限法则；
  - **全系经验与舰队补给**：反向五道门禁严格隔离，绝不给 6~30 补给小怪和 XP 经验敌人滥挂效率书。
- **修改器单槽独立精算与方向联动**：
  - 严禁全队盲目塞满道具，每个槽位独立精算；
  - 【团队协作】（增益 x2）仅在槽位真正接入相邻卡牌的左右指向增益时准入，孤立卡位物理禁用；
  - **出战前无损去冗**：若单卡+效率就能 100% 获胜，自动剔除多余的绿道具，杜绝浪费。
- **阶段全景排兵布阵（人机工程学革新）**：
  - 拒绝“单点盲目打一关看一关”；启动后先统揽当前阶段全部据点，一次性将卡牌与道具全量填入作战棋盘，打出战报大看板；
  - 留出仪式感停顿让玩家建立视觉心智，随后按威胁度阶梯行云流水依次攻坚。

## 快速上手与操作说明

1. 打开游戏行动页面，点击悬浮面板上的 **【自动选卡】**：
   * 脚本会自动统筹整阶段据点，将所有卡槽与修改器全部排布就绪，供玩家全景预览阵容。
2. 点击 **【自动游玩】**：
   * 脚本将先全景排兵布阵填满棋盘，确认无误后自动切入各据点依次出战、结算并推进阶段。
3. **安全门禁一票否决**：
   * 若面对极端恶劣词条，经四阶攻坚后关键目标（如修船包/煤炭）仍未达到安全胜率线，脚本会触发**安全门禁熔断**，自动暂停并报警，绝不将送死方案推向战场。
